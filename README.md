# 5-digit-Number-Wordle
5-digit Number Wordle
-A 5 digit random number between 10,000 and 99,999 inclusive is generated, and the user is prompted to guess the number.
-The game works like traditional wordle, returning the digits of the user's guess in different colours depending on whether they are in the right place or in the number at all. The program keeps track of this using dictionaries.
-If the user has not guessed the number after 10 attempts, the game is over.
